# Legacy proof-of-concept scripts

These files are the original experiments that proved `kiro-cli acp` can be driven from
Python. They are kept for reference only and are superseded by the `kiro_acp` package,
the `kiro-acp` utility, and `kiro-gateway`. See the top-level README.

- `kiro_acp_prompt.py` – single-prompt ACP client with interactive permissions
- `kiro_openai_gateway.py` – first OpenAI Chat Completions gateway (one process per request)
- `README.md` – documentation for the proof of concept
- `prompt-command-example.sh`, `requirements.txt`
